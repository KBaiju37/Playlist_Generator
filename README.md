# YouTube Music Mood Playlist Generator

A Streamlit app that turns a mood or scenario into a YouTube Music playlist. Gemini suggests songs, YouTube Music resolves them to tracks, and the app creates a playlist on the signed-in YouTube account.

## Features

- Describe a mood or scenario in natural language.
- Choose a playlist size by song count or target duration.
- Tune energy, era, familiarity, language, and explicit-content preferences.
- Include or avoid artists and limit the number of tracks per artist.
- Choose playlist privacy: private, unlisted, or public.
- Review the selected tracks and download a text tracklist.

## Requirements

- Windows
- Python 3.10 or later
- A Gemini API key
- A Google OAuth client configured for YouTube Data API v3

## Setup

Run these commands from the project root (the folder containing `app.py`):

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt.txt
```

Create a `.env` file in the project root with your own credentials:

```dotenv
GEMINI_API_KEY=your_gemini_api_key
YTMUSIC_CLIENT_ID=your_google_oauth_client_id
YTMUSIC_CLIENT_SECRET=your_google_oauth_client_secret
```

Get the Gemini key from Google AI Studio. In Google Cloud, enable YouTube Data API v3 and create an OAuth client. Use that OAuth client's ID and secret for the `YTMUSIC_...` variables. The downloaded OAuth client JSON is not loaded by the app; use it as the source for those values and keep it private.

Generate the YouTube authorization file from the same project root:

```powershell
ytmusicapi oauth
```

Follow the prompts and authorize the Google account where you want playlists created. This should create `oauth.json` in the project root. The app requires this file and the three environment variables above.

## Run

With the virtual environment activated and the working directory set to the project root:

```powershell
streamlit run app.py
```

Open the local URL printed by Streamlit, describe a mood, adjust the playlist options, and select **Generate playlist**.

## Project files

- `app.py` — Streamlit interface
- `ytmusic_backend.py` — Gemini, YouTube Music search, and playlist creation
- `requirements.txt.txt` — Python dependencies
- `.env` — local API credentials
- `oauth.json` — YouTube account authorization generated by `ytmusicapi oauth`

## Credential safety

Do not commit or share `.env`, `oauth.json`, or downloaded Google OAuth client credentials. They contain secrets or account tokens. If any of these files have been shared, revoke the affected credentials or account access and generate replacements.
